## Цель задания

Научиться применять базовые конструкции языка Go, включая условные операторы, циклы и функции, для решения практических задач обработки и анализа данных.

Закрепить навыки разработки программ на Go, включая реализацию алгоритмов, обработку пользовательского ввода и проверку корректности результатов, как основу для дальнейшей разработки сервисов обработки данных.

## Инструменты для выполнения задания

Вам понадобится:

- **Go** — для компиляции и запуска программ.
- **Visual Studio Code (VS Code)** с расширением **Go** — для написания и проверки кода.
- **GitHub** — для размещения исходного кода.

## Правила приёма работы

1. Выполните все 10 заданий на языке Go.
2. Разместите исходный код всех заданий в одном репозитории на GitHub, выделив для каждого задания отдельную папку.
3. Прикрепите в LMS ссылку на репозиторий с выполненной работой.
